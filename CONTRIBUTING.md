# Contributing to TodoDroid

Thank you! Whether on PC or Termux, you're welcome here.

## Setup (Phone / Termux)
pkg install git openjdk-17
git clone https://github.com/BLESS06703/TodoDroid.git

## Setup (Desktop)
Open in Android Studio or run ./gradlew assembleDebug

## How to Contribute
1. Open an Issue
2. Fork and create a branch
3. Submit a Pull Request

## Ideas
- More themes
- Fingerprint lock
- Task reminders
- Animations
